== Typical uses

Everything here is a button in VS Code and a line you can paste in Debian. Learn teaches each one step by step: the page name is in
brackets.

=== Start the day [start, repos]

Open VS Code from Debian with `code .` in a repository. Look at the line at the bottom. If it is green, you are ready. To bring every
repository up to date, press `Ctrl+Shift+P`, type `Workspace: Ensure everything is set up and up to date`, and press Enter. Any repository where you have
changes of your own is left exactly as it was, and the result says so.

=== Choose which repositories you work in [start]

To add one, type its address in Debian. `ws-host` puts it on your own list and copies it now, and it is kept up to date from then on:

----
ws-host repo add github.com/ORG/REPO
----

To remove one or change the list, open your settings file in VS Code and edit the line that starts with `WS_HOST_REPOS`:

----
code ~/.config/workspaces-host/ws-host.env
----

Until you add your own, you have the two starters. A list you write replaces them, and an empty list (`WS_HOST_REPOS=""`) means none.

=== A repository was left alone [recover]

That means it has changes you have not saved to a commit, or yours and the shared copy have both moved on. Your work is safe. Commit or
push your changes, then bring everything up to date again.

=== Install a kit [kits]

A kit is a set of tools for one kind of work. In Debian:

----
ws-host kit list
ws-host kit add press
----

The second asks for your password, because it installs packages. `press` typesets books and PDFs, `rust` builds Rust programs, and `shell`
gives you a friendlier terminal.

=== Check your work [editor]

Press `Ctrl+Shift+P`, type `Workspace: Run checks`. Anything wrong appears in the *Problems* panel, where you can click to go to it.

=== Make your terminal friendlier [shell]

`ws-host kit add shell` installs fish and oh-my-posh. Type `fish` to try it, and nothing else changes. `ws-host help shell` has the lines to
make it permanent. bash and oh-my-posh work fine if you would rather stay as you are.

=== Work with an AI [ai]

An AI can run everything `ws-host` does except the decisions that are yours. Give it the report from *Workspace: Get help*.

=== Update ws-host itself

`ws-host workspace ensure` also brings `ws-host` up to date, because it is one of your repositories. Reload VS Code afterward.

=== Something is wrong and I am not sure what

Press `Ctrl+Shift+P`, type `Workspace: Get help`. It copies a report with no passwords in it. Paste it to someone who helps you, or to an AI.
Or look in <<troubleshooting>>.
