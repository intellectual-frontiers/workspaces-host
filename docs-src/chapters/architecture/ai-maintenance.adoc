== Maintaining ws-host with an AI

An AI agent can do most maintenance here well, because the system is code, discovered by presence, and checked by tests. It does it badly when it is asked vaguely, when it is allowed to guess a checksum, or when nobody asks it to prove the result. This chapter turns the rest of Part III into a way of asking.

=== What to tell the AI first

Start every session with the same three things:

. *Read `.claude/skills/ws-host/SKILL.md`.* It is generated from the code, lists every command and kit and says which commands an agent is not offered.
. *Read the chapter for the layer you are changing,* from this part of the guide, and the spec in `spec-kit/specs/` that governs it.
. *Say which proof you want.* Always the same four commands: `ws-host test`, `ws-host check`, `ws-host fresh` and `ws-host doctor`. Add `ws-host check console`, `check release` or `check reproducible` when the change touches the extension or the release.

=== Rules to put in every prompt

* *Never invent a version or a checksum.* Fetch the real artifact and hash it, and say where.
* *Never edit a generated file.* Run its generator.
* *Never weaken a safety rule to pass a test.* The sync, trust and decision rules are the product.
* *Never add a package at module level in a command or kit.* A dependency goes in a group in `pyproject.toml` and is imported inside the function.
* *Do not run what is a person's decision.* An agent does not run `release publish`, `provider add`, `repo set` or `kit add`.
* *Keep the change small.* One layer, one purpose, and a test that fails without it.
* *Say what you did not verify.* Several checks skip on a machine without a display, `agora` or a real VS Code.

=== A review checklist for what comes back

. Does the change sit in the layer the chapter says it should?
. Is there a test that would fail without it, using a real temporary git repository or a throwaway home where the behavior touches files?
. Did the generated files change, and are they committed?
. Is any version or hash new, and is its source named?
. Did a safety rule move? If so, why?
. Were any checks skipped, and were they run somewhere that could?
